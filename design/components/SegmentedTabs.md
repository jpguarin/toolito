# SegmentedTabs

A pill-shaped row of two to four tabs that switches how a tool works (for example, Split PDF: Pick pages · Ranges · Every page).

- `role="tablist"` with `role="tab"` buttons and `aria-selected`; arrow keys move between tabs; each tab controls a `role="tabpanel"`.
- Container `paper`, `border-md` `line`, `radius-pill`; dividers `border-md` `line`.
- Selected: `panel` fill with `led` text. Unselected: transparent, `ink`.
- Work Sans 800 15px, min-height 46px.

Not for theme selection — there is none.
