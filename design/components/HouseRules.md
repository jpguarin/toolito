# HouseRules

The privacy promise written as a laundromat's posted rules, on the home page and summarised on tool pages.

- `paper` panel, `border-thick` `line`, `radius-md`, padding 28 × 32.
- Title "House rules" in `sign-lg`, colour `heading`.
- Ordered list, `body` style, each rule = bold promise + one plain sentence.
- Signed "— The management" in `muted`.

## The rules (keep wording in sync with the Privacy page)

1. We never look in your basket. — local tools.
2. Nothing gets left behind. — the dryer deletes after every load.
3. No coins needed. — free, no sign-up, no watermarks.
4. Lights follow the clock. — night theme after 7 p.m. local time.

Never promise more than the code does. If analytics are added, add a rule.
