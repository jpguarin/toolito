# Toolito web

Astro site for Toolito. See the root `README.md` and `PLAN.md` for context.

```bash
nvm use          # Node version from .nvmrc
npm install
npm run dev      # http://localhost:4321
npm run check    # TypeScript and .astro type checks
npm test         # Unit tests (Vitest)
npm run build    # Static site in dist/ (+ service worker)
npm run preview  # Serve dist/ at http://localhost:4322 (offline/PWA testing)
```
